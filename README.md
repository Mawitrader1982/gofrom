# GoFrom

Native Android V1 for the GoFrom health and fitness app, built with Kotlin and Jetpack Compose.

## Build

Open the project in Android Studio or run `./gradlew assembleDebug`. The APK is written to `app/build/outputs/apk/debug/app-debug.apk`.

Every push to `main` also builds the APK with GitHub Actions. The workflow can be started manually from the Actions tab and uploads a `gofrom-debug-apk` artifact.
